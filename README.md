# dexon-media

Imágenes **ya aprobadas** de DEXON PADEL (Tavapy, Alto Paraná) para publicar en Instagram y Facebook.

Este repositorio es público a propósito: las herramientas de programación de redes (Buffer) solo
pueden leer imágenes desde una dirección pública. Por eso acá van únicamente piezas finales,
nunca fotos originales, y nunca fotos con personas sin su permiso.

Las piezas las genera la skill `dexon-marketing` del repositorio privado `dexon-padel`.
Cada paquete va en su carpeta, por ejemplo `2026-10-semana-1/`.
